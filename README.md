# ワードウルフ

ブラウザで遊べるワードウルフ（お題当て・人狼系パーティーゲーム）です。プレイヤーごとに異なる単語が配られ、話し合いの中で「人狼」（違う単語を持っている人）を当てます。

## 遊び方

1. このリポジトリの `index.html` をブラウザで開く（ダブルクリック、またはローカルサーバー経由）
2. 人数・お題カテゴリなどを設定してゲーム開始
3. 各プレイヤーが画面を順番に見て自分の単語を確認
4. 制限時間内に議論し、人狼を投票で特定する

## 開き方（ローカル）

```bash
# 例: Python の簡易サーバー
cd wordwolf
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

または `index.html` をブラウザに直接ドラッグ＆ドロップしても動作します。

## GitHub Pages（任意）

リポジトリ設定で Pages を有効にし、ソースを `main` ブランチのルートにすると、公開 URL で遊べます。

## 技術

HTML / CSS / JavaScript に分割しています。ビルド不要です。`index.html` を開いてください。
